مسئله ۲: حل معادله درجه دوم (Quadratic Equation)

سطح: متوسط | شرط‌ها و تاپل‌ها

تابعی با نام solve_quadratic(a, b, c) پیاده‌سازی کنید که ضرایب معادله درجه دو زیر را دریافت کند:

$$ax^2 + bx + c = 0 \quad (a \neq 0)$$

ریشه‌های حقیقی معادله را با استفاده از مبین دلتا ($\Delta = b^2 - 4ac$) محاسبه کرده و به شکل یک تاپل (tuple) مرتب‌شده از کوچک به بزرگ بازگردانید.

⚠️ نکات کلیدی:
  • خروجی حتماً باید از نوع tuple باشد.
  • اگر دو ریشه وجود داشت، اول ریشه کوچک‌تر و سپس بزرگ‌تر قرار گیرد: (x1, x2) به طوری که $x_1 \le x_2$.
  • اگر ریشه مضاعف داشت ($\Delta = 0$)، یک تاپل تک‌عضوی باشد: (x,).
  • اگر معادله ریشه حقیقی نداشت ($\Delta < 0$)، تاپل خالی باشد: ().
📋 مشخصات تابع (Contract):
نام تابع پارامترهای ورودی نوع خروجی
solve_quadratic(a, b, c) a, b, c: float | int tuple (تاپل مرتب ریشه‌ها)
🔍 نمونه‌های تست و رفتار تابع:
فراخوانی نمونه خروجی مورد انتظار توضیح
solve_quadratic(1, -5, 6) (2.0, 3.0) $\Delta = 1 > 0$؛ دو ریشه حقیقی $2$ و $3$
solve_quadratic(1, -4, 4) (2.0,) $\Delta = 0$؛ ریشه مضاعف $2$
solve_quadratic(1, 0, 1) () $\Delta = -4 < 0$؛ بدون ریشه حقیقی

  1. مقدار دلتا را با فرمول delta = b**2 - 4*a*c محاسبه کنید.
  2. اگر delta < 0 بود، بلافاصله تاپل خالی را برگردانید: return ()
  3. اگر delta == 0 بود، ریشه برابر است با -b / (2*a) و تاپل تک‌عضوی برگردانید: return (-b / (2*a),) (کاما بعد از عدد الزامی است تا پایتون آن را تاپل تشخیص دهد).
  4. اگر delta > 0 بود، دو ریشه را حساب کنید: x1 = (-b - math.sqrt(delta)) / (2*a) و x2 = (-b + math.sqrt(delta)) / (2*a) و به صورت مرتب برگردانید: return (min(x1, x2), max(x1, x2)).
