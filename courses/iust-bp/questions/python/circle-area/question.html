مسئله ۱: محاسبه مساحت دایره (Circle Area)

سطح: مقدماتی | توابع و محاسبات

تابعی با نام circle_area(r) پیاده‌سازی کنید که شعاع یک دایره ($r$) را به عنوان ورودی دریافت کرده و مساحت دایره را با فرمول $\pi r^2$ محاسبه کند و بازگرداند.

⚠️ نکته بسیار مهم: تابع شما باید حاصل مساحت را با دستور return برگرداند. از نوشتن input() یا print() داخل تابع خودداری فرمایید.
📋 مشخصات تابع (Contract):
نام تابع پارامترهای ورودی نوع خروجی
circle_area(r) r: float | int (شعاع دایره) float | int (مساحت دایره یا ۰)
🔍 نمونه‌های تست و رفتار تابع:
فراخوانی نمونه خروجی مورد انتظار توضیح و منطق
circle_area(1) 3.14159... $\pi \times 1^2 = \pi$
circle_area(2.5) 19.63495... $\pi \times 2.5^2$
circle_area(0) 0.0 شعاع صفر، مساحت صفر
circle_area(-3) 0 شعاع منفی نامعتبر است و طبق صورت سوال باید ۰ برگردد.

  1. برای استفاده از مقدار دقیق عدد پی، ماژول ریاضی را ایمپورت کنید: import math
  2. ابتدا با یک شرط بررسی کنید: اگر $r < 0$ بود، فوراً return 0 را برگردانید.
  3. در غیر این صورت، مقدار math.pi * (r ** 2) را محاسبه کرده و return کنید.

  • خطای NoneType: اگر تست می‌گوید خروجی None دریافت شده است، به این معنی است که به جای return از print() استفاده کرده‌اید.
  • خطای دقت اعشار: از نوشتن مقدار تقریبی 3.14 به جای math.pi خودداری کنید.
