مسئله ۳: تشخیص عدد اول (Prime Number Checker)

سطح: متوسط | حلقه‌ها و کارایی الگوریتم

تابعی با نام is_prime(n) پیاده‌سازی کنید که یک عدد صحیح $n$ را دریافت کرده و در صورتی که عدد اول باشد مقدار True و در غیر این صورت مقدار False را برگرداند.

⚠️ نکات کلیدی:
  • تابع باید مقدار بولین True یا False را با return بازگرداند (نه چاپ با print).
  • اعداد کوچک‌تر یا مساوی ۱ (شامل اعداد منفی، صفر و یک) اول نیستند.
  • کد شما باید بهینه باشد تا برای اعداد بزرگ به خطای محدودیت زمانی (Time Limit) نخورد.
📋 مشخصات تابع (Contract):
نام تابع پارامترهای ورودی نوع خروجی
is_prime(n) n: int (عدد صحیح مورد بررسی) bool (مقدار True یا False)
🔍 نمونه‌های تست و رفتار تابع:
فراخوانی نمونه خروجی مورد انتظار توضیح و منطق
is_prime(7) True تنها بر ۱ و ۷ بخش‌پذیر است.
is_prime(4) False بر ۲ نیز بخش‌پذیر است.
is_prime(1) False عدد ۱ طبق تعریف عدد اول نیست.
is_prime(-5) False اعداد منفی اول نیستند.

  1. ابتدا بررسی کنید آیا $n \le 1$ است؛ اگر بله، بلافاصله return False.
  2. اگر $n == 2$ بود، عدد اول است و return True.
  3. اگر $n$ زوج بود ($n \pmod 2 == 0$)، اول نیست و return False.
  4. برای بقیه اعداد، بررسی مقسوم‌علیه‌ها را از ۳ با گام‌های ۲ تایی تا $\lfloor\sqrt{n}\rfloor + 1$ ادامه دهید. اگر بر هیچ مقسوم‌علیهی بخش‌پذیر نبود، return True.

خیلی از دانشجویان داخل حلقه دستور else: return True می‌گذارند! این کار غلط است چون به محض اینکه عدد بر اولین شمارنده بخش‌پذیر نباشد، حلقه قطع می‌شود. دستور return True باید بعد از اتمام کامل حلقه قرار گیرد.
