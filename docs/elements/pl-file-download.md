# المان `pl-file-download`

ارائه یک پیوند (لینک) دانلود برای یک فایل ایستا (static) یا تولیدشده به صورت پویا (dynamically generated).

## نمونه المان

![تصویر المان pl-file-download](pl-file-download.png)

```html title="question.html"
<!-- امکان دانلود یک فایل موجود برای دانشجویان -->
<pl-file-download file-name="data.txt" directory="clientFilesCourse"></pl-file-download>

<!-- امکان دانلود فایلی که با کد تولید شده است برای دانشجویان -->
<pl-file-download file-name="data.txt" type="dynamic"></pl-file-download>

<!-- امکان باز کردن یک فایل موجود در یک برگه جدید برای دانشجویان -->
<pl-file-download
  file-name="data.txt"
  directory="clientFilesCourse"
  force-download="false"
></pl-file-download>
```

## سفارشی‌سازی‌ها

| ویژگی | نوع | پیش‌فرض | توضیحات |
| ---------------- | ------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `directory`      | string                    | `"clientFilesQuestion"` | پوشه‌ای که فایل را در بر دارد؛ یا `"clientFilesQuestion"` یا `clientFilesCourse` (به [فایل‌های کلاینت و سرور](../clientServerFiles.md) مراجعه کنید). اگر `type="dynamic"` باشد دایرکتوری را نمی‌توان مشخص کرد.                                                                                      |
| `file-name`      | string                    | —                       | نام فایل جهت دانلود.                                                                                                                                                                                                                                                                       |
| `force-download` | boolean                   | true                    | اجبار به دانلود فایل. در غیر این صورت، به مرورگر اجازه می‌دهد فایل را در یک برگه (تب) جدید باز کند.                                                                                                                                                                                                              |
| `label`          | string                    | به توضیحات مراجعه کنید         | برچسب نمایش‌داده‌شده روی پیوند دانلود. به‌طور پیش‌فرض برابر با نام فایل مشخص‌شده در `file-name` است. در صورت تنظیم صریح می‌تواند شامل کدهای HTML باشد، هرچند کد باید به درستی اسکیپ (escape) شود (به‌عنوان مثال، برای برچسب `<strong>Download</strong> File` از `label="&lt;strong&gt;Download&lt;/strong&gt; File"` استفاده کنید). |
| `type`           | `"static"` یا `"dynamic"` | `"static"`              | نوع فایل؛ یا `"static"` (یک فایل موجود) یا `"dynamic"` (فایلی که توسط کد المان یا سرور تولید شده است).                                                                                                                                                                                 |

## جزئیات

اگر `type="dynamic"` باشد، محتویات فایل باید توسط یک تابع `file()` که در کد المان یا در `server.py` قرار دارد بازگردانده شود. محتوا باید یک رشته (با انکودینگ utf-8)، یک شیء شبه‌بایت (bytes-like object) یا یک شیء شبه‌فایل (file-like object) باشد. نام فایل به صورت `data["filename"]` در دسترس این تابع خواهد بود. به عنوان مثال، این کد ممکن است در `server.py` برای تولید فایلی به نام `data.txt` قرار گیرد:

```python title="server.py"
def file(data):
    if data["filename"] == "data.txt":
        return "This data is generated by code."
```

اگر `file()` چیزی بازنگرداند، همانند این رفتار خواهد شد که `file()` یک رشته خالی برگردانده است.
