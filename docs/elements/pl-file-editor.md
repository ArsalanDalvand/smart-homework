# المان `pl-file-editor`

یک ویرایشگر فایل درون مرورگر فراهم می‌کند که با سایر المان‌های فایل و سیستم نمره‌دهی خارجی (external grading) سازگار است.

## نمونه المان

![تصویر المان pl-file-editor](pl-file-editor.png)

<!-- prettier-ignore -->
```html title="question.html"
<pl-file-editor
  file-name="fib.py"
  ace-mode="ace/mode/python"
  ace-theme="ace/theme/monokai"
>
def fib(n):
    pass
</pl-file-editor>
```

## سفارشی‌سازی‌ها

| ویژگی | نوع | پیش‌فرض | توضیحات |
| -------------------- | ------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ace-mode`           | string  | —                    | یک حالت (mode) ویرایشگر Ace را جهت فعال‌سازی مواردی مانند تورفتگی هوشمند کد و برجسته‌سازی نحو مشخص می‌کند. می‌تواند روی [یک حالت پیش‌فرض Ace یا یک حالت تعریف‌شده توسط درس](#حالت‌های-ویرایشگر) تنظیم شود.                                                                                                                                                                                                                         |
| `ace-theme`          | string  | `"ace/theme/chrome"` | پوسته (تم) ویرایشگر Ace را مشخص می‌کند؛ لیست کامل پوسته‌ها را در [مخزن گیت‌هاب Ace](https://github.com/ajaxorg/ace/tree/master/src/theme) ببینید.                                                                                                                                                                                                                         |
| `allow-blank`        | boolean | false                | مشخص می‌کند که آیا ارسال پاسخ خالی مجاز است یا خیر.                                                                                                                                                                                                                                                                                                                                                                                    |
| `auto-resize`        | boolean | true                 | پنل ویرایشگر را به طور خودکار گسترش می‌دهد تا اطمینان حاصل شود تمام خطوط نمایش داده می‌شوند. هر مقداری که توسط `"max-lines"` تنظیم شده باشد را لغو می‌کند و در صورت ارائه نشدن، مقدار پیش‌فرض ۱۸ خط را برای `"min-lines"` تعیین می‌کند. برای نکات بیشتر به بخش جزئیات زیر مراجعه کنید.                                                                                                                                                                                                                              |
| `directory`          | string  | به توضیحات مراجعه کنید      | پوشه‌ای که فایل منبع حاوی کد موجود در آن قرار دارد. فقط زمانی کاربرد دارد که `source-file-name` استفاده شده باشد. اگر شامل یکی از نام‌های ویژه `"clientFilesCourse"` یا `"serverFilesCourse"` باشد، نام فایل منبع از پوشه‌های ویژه درس خوانده می‌شود، در غیر این صورت انتظار می‌رود پوشه در پوشه خود سوال قرار داشته باشد. اگر ارائه نشود، انتظار می‌رود فایل منبع در پوشه اصلی سوال یافت شود. |
| `file-name`          | string  | —                    | نام این فایل؛ برای ذخیره این فایل در پاسخ ارسالی `"_files"` استفاده خواهد شد.                                                                                                                                                                                                                                                                                                                                                                |
| `focus`              | boolean | false                | مشخص می‌کند که آیا ویرایشگر با فوکوس روی پنجره ویرایش و تسخیر مکان‌نما شروع به کار کند یا خیر. برای نکات بیشتر به بخش جزئیات زیر مراجعه کنید.                                                                                                                                                                                                                                                                                                 |
| `font-size`          | string  | `"12px"`             | اندازه قلم (فونت) را برای ویرایشگر Ace تعیین می‌کند. به عنوان یک اندازه سبک CSS مشخص می‌شود (مانند `"1rem"`، `"110%"`، `"16pt"` یا `"20px"`).                                                                                                                                                                                                                                                                                                    |
| `max-lines`          | integer | —                    | حداکثر تعداد خطوطی که ویرایشگر باید هم‌زمان نمایش دهد. باید بزرگ‌تر از `min-lines` باشد.                                                                                                                                                                                                                                                                                                                                                              |
| `min-lines`          | integer | —                    | حداقل تعداد خطوطی که ویرایشگر باید در ابتدا نمایش دهد.                                                                                                                                                                                                                                                                                                                                                                                                 |
| `normalize-to-ascii` | boolean | false                | مشخص می‌کند که آیا کاراکترهای غیرانگلیسی (اعراب‌ها، الفباهای غیرلاتین، گیومه‌های خاص) باید قبل از ارسال فایل برای نمره‌دهی به کاراکترهای معادل انگلیسی نرمال‌سازی شوند یا خیر.                                                                                                                                                                                                                                                                                 |
| `preview`            | string  | —                    | در صورت تنظیم، یک حالت پیش‌نمایش زنده برای ویرایش زبان‌های نشانه‌گذاری فراهم می‌کند. در حال حاضر مقادیر `"html"`، `"markdown"` یا `"dot"` در دسترس هستند، هرچند [زبان‌های بیشتر از طریق افزونه‌ها پشتیبانی می‌شوند](#گزینه‌های-پیش‌نمایش-سفارشی).                                                                                                                                                                                                                                      |
| `source-file-name`   | string  | —                    | نام فایل منبع حاوی کد موجود برای نمایش در ویرایشگر متن مرورگر (به جای نوشتن کد موجود در بین تگ‌های المان همان‌طور که در قطعه کد بالا نشان داده شده است).                                                                                                                                                                                                                                                           |

## جزئیات

هنگام استفاده از `auto-resize`، تعیین مقدار سفارشی برای `min-lines` یا پر کردن اولیه پنجره ویرایشگر با یک نمونه کد را مد نظر قرار دهید. این کار ناحیه ویرایشگر را با تعداد خطوط کافی مقداردهی اولیه می‌کند تا تمام کدها به طور هم‌زمان و بدون نیاز به اسکرول نمایش داده شوند.

ویژگی `focus` به طور پیش‌فرض روی `false` تنظیم است. تنظیم این ویژگی روی `true` باعث می‌شود تا المان ویرایشگر فایل هنگام بارگذاری صفحه سوال به طور خودکار فوکوس مکان‌نما را دریافت کند، که این امر ممکن است باعث اسکرول صفحه به پایین شود تا ویرایشگر فایل در دید قرار گیرد و مقدمه نوشته‌شده نادیده گرفته شود. این ممکن است پیامدهای منفی برای دسترس‌پذیری با صفحه‌خوان‌ها داشته باشد، بنابراین با احتیاط استفاده کنید. اگر چندین ویرایشگر فایل در یک صفحه سوال دارید، فقط یک المان باید `focus` آن روی `true` تنظیم شود، در غیر این صورت رفتار ممکن است غیرقابل پیش‌بینی باشد.

محتویات ویرایشگر فایل به طور پیش‌فرض فقط در پنل سوال نمایش داده می‌شود. اگر انتظار می‌رود محتویات در پنل ارسال پاسخ (submission panel) فهرست شوند، باید صریحاً با استفاده از المان‌های دیگر مانند [`pl-file-preview`](pl-file-preview.md) یا [`pl-xss-safe`](pl-xss-safe.md) اضافه شوند.

### حالت‌های ویرایشگر

ویژگی `ace-mode` معمولاً روی `ace/mode/<language_name>` تنظیم می‌شود، که در آن `<language_name>` نام یک زبان پشتیبانی‌شده توسط ویرایشگر Ace است (مثلاً `ace/mode/python`، `ace/mode/c_cpp`، `ace/mode/java` و غیره). ویرایشگر Ace از چندین حالت توکار بر اساس فهرست حالت‌ها در [مخزن گیت‌هاب Ace](https://github.com/ajaxorg/ace/tree/master/src/mode) پشتیبانی می‌کند.

به عنوان جایگزین، مدرسان می‌توانند یک حالت سفارشی تعریف کنند که می‌تواند راهکاری برای زبان‌هایی باشد که به صورت بومی توسط Ace پشتیبانی نمی‌شوند، یا برای زبان‌های ساخته‌شده توسط درس، یا مواردی که مدرسان مایلند پشتیبانی از یک زبان را به مجموعه‌ای از ویژگی‌های از پیش تعیین‌شده محدود کنند. [مستندات Ace](https://ace.c9.io/#nav=highlighter) اطلاعات بیشتری درباره نحوه ایجاد حالت‌های سفارشی ارائه می‌دهد. پس از ایجاد حالت سفارشی، آن را با نام `ace/mode/mode-<language_name>.js` در داخل [`clientFilesQuestion` یا `clientFilesCourse`](../clientServerFiles.md) ذخیره کنید. المان `pl-file-editor` به طور خودکار تشخیص می‌دهد که یک حالت سفارشی وجود دارد و هنگامی که ویژگی `ace-mode` به درستی تنظیم شده باشد، فایل حالت سفارشی را بارگذاری می‌کند.

### گزینه‌های پیش‌نمایش سفارشی

این المان از گزینه‌های پیش‌نمایش اضافی از طریق [افزونه‌های المان](../elementExtensions.md) پشتیبانی می‌کند. برای ارائه این قابلیت، افزونه باید تابعی را به `window.PLFileEditor.prototype.preview.PREVIEW_TYPE` (که در آن `PREVIEW_TYPE` مقدار ویژگی `preview` است) اختصاص دهد که یک رشته نمایانگر محتوای ویرایشگر را به محتوای HTML مناسب تبدیل می‌کند.

## نمره‌دهی با هوش مصنوعی (AI grading)

کد ارسالی در [نمره‌دهی هوش مصنوعی](../aiGrading/index.md) به عنوان متن برچسب‌گذاری‌شده با نام فایل آن گنجانده می‌شود و تورفتگی و شکستگی خطوط حفظ می‌شود. وقتی `normalize-to-ascii` غیرفعال است (حالت پیش‌فرض)، یونیکد حفظ می‌شود؛ فعال کردن آن کاراکترهای غیر ASCII را قبل از ارسال نرمال‌سازی می‌کند. المان [`pl-file-preview`](pl-file-preview.md) برای نمره‌دهی هوش مصنوعی الزامی نیست، اما توصیه می‌شود تا دانشجویان بتوانند فایل‌های ارسالی خود را بررسی کنند. سوالات می‌توانند ویرایشگر را با آپلود فایل و گرفتن تصویر ترکیب کنند؛ هر فایل ارسالی متمایز تنها یک بار ارسال می‌شود.
